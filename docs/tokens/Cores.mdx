# Cores

Os tokens são divididos em três grupos em `tokens/tokens.json`:

- **`color`**: compartilhados entre web e mobile (mesmo valor; o nome muda: `ink` na web, `textPrimary` no app);
- **`web.color`**: só da web (hover, links, rodapé, mock de iPhone…);
- **`mobile.color`**: só do app (toast, interruptor, scrim…).

## Marca

Iguais nos dois temas e nas duas plataformas. Tailwind: `bg-caramelo`, `text-ferrugem`… · Swift: `ToskiColors.caramelo`.

## Contraste

Pares conferidos no CI (`npm run contrast`), com o nome de cada plataforma. Texto: mínimo **4,5:1**.
Texto grande, ícones e foco: **3:1** (linhas em fonte maior). Na web, use `accent-text` (não `accent`)
para texto pequeno sobre `tint` e `hero`.
