# Raios e layout

## Raios — web

CSS: `var(--toski-radius-card)` · Tailwind: `rounded-card`.

<Radii platform="web" />

## Raios — mobile

Swift: `ToskiRadius.card`. Mesmos valores; `icon` se chama `iconBox` e `panel` se chama `sheet` no app.
Só no app: `checkbox`, `swatch`, `pdfPage`, `small`, `buttonSmall`, `segmentTrack`, `input`, `tile`,
`notification` e `appIcon` (raio 22 num lado de referência 96, proporcional ao tamanho). Pílula e círculo
não têm token: no SwiftUI são `Capsule` e `Circle`.

<Radii platform="mobile" />

## Layout (web)

<Layout />
